数据口径：新闻与论文按真实事件时间；Stars 为[连续快照精确差值 / 实际 N 小时差值 / 估算]。

## 今日速览

- 最重要变化及原因
- 第二重要变化
- GitHub 绝对增星与相对增长领先者

## AI 新闻

1. **一句话结论**

   - 来源：[原始来源](URL)

## 最新论文

1. **标题**（首次提交/实质修订，时间）
